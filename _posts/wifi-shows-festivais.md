Imagine 30.000 pessoas num festival. Cada uma com pelo menos um smartphone no bolso. Metade delas tentando postar uma foto no Instagram ao mesmo tempo. O que acontece com uma rede Wi-Fi comum nessa situação? Ela simplesmente trava.

Prover conectividade em eventos de grande porte é um dos maiores desafios da infraestrutura técnica. Neste artigo, vamos explicar como os profissionais resolvem esse problema.

## Por que o Wi-Fi comum não funciona em grandes eventos?

O roteador da sua casa foi projetado para atender 20, 30 dispositivos no máximo. Num festival com 10.000 pessoas, você teria um problema monumental com equipamentos domésticos.

Os principais problemas são:

- **Saturação de canais:** muitos dispositivos no mesmo canal de frequência causam interferência
- **Capacidade de clientes:** roteadores comuns suportam poucos dispositivos simultâneos
- **Cobertura:** um único ponto de acesso não cobre grandes áreas
- **Banda insuficiente:** sem um link robusto, nada funciona independente dos access points

## A solução: Wi-Fi de alta densidade

Para grandes eventos, a solução é implementar uma **rede de alta densidade**, com múltiplos access points enterprise distribuídos estrategicamente. Veja como funciona:

### 1. Planejamento de RF (Radiofrequência)

Antes de qualquer instalação, fazemos um projeto de radiofrequência — mapeando o espaço, identificando obstáculos, calculando a distância ideal entre os access points e os canais a serem utilizados para evitar interferência.

### 2. Access points enterprise

Equipamentos como Cisco, Ubiquiti UniFi e Aruba suportam centenas de dispositivos por access point, com tecnologias como:

- **MU-MIMO:** atende múltiplos dispositivos simultaneamente
- **Band steering:** direciona dispositivos para a frequência 5GHz quando possível (menos congestionada)
- **Roaming inteligente:** o dispositivo troca de AP sem perder conexão ao se mover pelo espaço

### 3. Distribuição estratégica dos APs

Em vez de poucos APs com alta potência (que causam interferência), usamos muitos APs com potência moderada, distribuídos em grid. Isso garante cobertura uniforme e evita zonas de sombra.

Para uma área de 10.000 m², por exemplo, podemos usar 40 a 60 access points dependendo da densidade esperada de dispositivos.

### 4. Segmentação por perfil de usuário

Dividimos a rede em SSIDs (redes Wi-Fi) separados por perfil:

- **Staff:** prioridade máxima, para operação do evento
- **Imprensa:** alta prioridade, acesso dedicado
- **VIP:** prioridade média-alta
- **Público geral:** prioridade padrão, com limite de banda por dispositivo

Essa segmentação garante que a operação nunca seja afetada pelo uso do público.

### 5. Link de entrada robusto

De nada adianta ter 60 access points enterprise se o link de internet for fraco. Para grandes eventos, dimensionamos o link de entrada com base no número de usuários e tipo de uso, sempre com margem de segurança.

## Casos reais: o que aprendemos na prática

Atendemos eventos com dezenas de milhares de pessoas, como a **Micareta 10ª Edição** e o **Festival Trama**, e cada um nos ensinou algo novo.

Alguns aprendizados importantes:

- **Teste sempre antes:** uma vistoria técnica prévia evita 90% dos problemas
- **Tenha backup:** um link 4G/5G de contingência pode salvar o evento
- **Monitore em tempo real:** ter visibilidade da rede durante o evento permite agir antes que o problema afete os usuários
- **Documente:** um relatório pós-evento com dados de uso ajuda a planejar melhor o próximo

## Checklist para Wi-Fi em grandes eventos

- [ ] Vistoria técnica no local pelo menos 7 dias antes
- [ ] Projeto de RF com posicionamento dos APs
- [ ] Link de entrada dimensionado corretamente
- [ ] Segmentação de redes por perfil
- [ ] Testes de carga antes do evento
- [ ] Técnico presencial durante o evento
- [ ] Link de backup ativo
- [ ] Monitoramento em tempo real
